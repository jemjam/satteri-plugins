# Astro Starter Kit: Minimal

```sh
pnpm create astro@latest -- --template minimal
```

---

This is the minimal astro template, integrating a couple of workspace plugins
(only) to demonstrate the full satteri markdown rendering pipeline.

- `astro.config.mjs`: Config file that enables markdown and includes plugins.
- `src/pages/example.md`: Page rendered at `/example` that demonstrates the
  satteri plugins in action.
